# TheFEYA → Bonanza: проверенный комплект CSV (12 октября 2026)

## Стоп-контроль обнаружен 12 октября 2026 — импорт недоступен до проверки магазина

**В кабинете DariaL20 на странице Import items from an inventory file отображено точное предупреждение:**

> One or more recently added items in your booth require administrative review. Booths are reviewed within 72 hours (usually much sooner). You will be able to import items once your booth has been reviewed.

Поэтому **не выбирать файл и не нажимать Import items** сейчас. Прежде нужно подтверждение фактического прохождения проверки магазина и исчезновение блокировки. Надпись `Your import is complete` касается старого импорта **30 марта: 204 найдено, 202 импортированы, 2 пропущены**, а не нашего пилота.

Поддержка Bonanza в письме от 31.03.2026 `#1330144 need an export template` выслала **ссылку на инструкцию**, а не CSV/XLS шаблон. Поиск в шести подключённых Gmail-аккаунтах не выявил отдельного Bonanza CSV-шаблона во вложениях. Не путать с давним уведомлением об экспорте через Batch Editor.

### Безопасное действие перед исправлением импорта

1. Выйти из формы `Inventory File Import Settings` без загрузки.
2. Перейти в `Selling → Add or edit items`. На **твоём скриншоте** верхняя панель содержит кнопку `Update items as group`.
3. Нажать **`Update items as group`**, только открыть групповой редактор, не применять массовых правок.
4. Показать левое меню страницы. Если там есть `Inventory Details`, открыть его и найти `Export filtered items`. Если интерфейс отличается, остановиться и прислать скриншот.
5. Выгрузить резервный CSV/ZIP текущих 202 товаров, если доступен, и передать файл для сопоставления оригинальных Bonanza IDs/SKUs и заголовков.
6. **Категории старых 201 неполных карточек не менять массово**: по официальному руководству установка правильной категории может автоматически перевести `Incomplete` в `For sale` (https://bonanza.zendesk.com/hc/en-us/articles/360000608812-Setting-Categories-in-Bulk).
7. Старый импорт не удалять и `Update Booth` не нажимать.

Это экспорт для резервной копии и исследований, **не обход административной проверки**, и он может быть доступен даже когда новый импорт заблокирован. Если кнопки экспорта нет или проверка так и не снимается, нужно решить именно вопрос ревью магазина в Bonanza, **а не просить поддержку загружать товары**.

Ссылки: https://www.bonanza.com/community_help/can_i_export_a_list_of_bonanza_items_as_csv_file_ , https://www.bonanza.com/blog/selling/using_csv_file_to_import___update_listings



**Ограничение:** официальная инструкция Bonanza подтверждает основные заголовки `id,title,price,category,description` и дополнительные `quantity,image`, но не раскрывает точного формата CSV для Configuration + Color с отдельными ценами. Эти файлы НЕ являются гарантией корректного импорта вариаций.

## Первый тестовый CSV

Одна строка с полями `id,title,price,category,description,quantity,image`. Содержание:
- `id = TF-BZ-FS-4367470907` — уникальный внешний идентификатор, не совпадает с простым Etsy ID.
- `title = Silver Metallic Festival Costume - Full Set Only` — 53 символа, до ограничения Bonanza 80.
- `price = 295.09` — полная стоимость набора, не минимальная стоимость гартеров $96.50.
- `category = 53369` — категория-кандидат Costumes > Women, сверить на экране после импорта.
- `description` — фактический полный комплект в серебряном исполнении; не подразумевает доступность отдельной детали.
- `quantity = 0` — специально для попытки создания непокупаемого черновика. **Не подтверждено, что CSV-импортёр примет это значение.** Если его отвергнет, не меняй на 1 автоматически.
- `image` — настоящая фотография из источника TheFEYA.

## Единственная разрешённая операция пользователю сейчас

1. Войти в существующий аккаунт `DariaL20` и открыть **Selling → Import from inventory file**. Пункт импортировать из Etsy **НЕ выбирать**, потому что в прошлом он потерял описания и вариации.
2. В `Inventory File Import Settings` осмотреть возможные опции. **Не выбирать** `Revise previously imported items` и другие режимы overwrite/sync/update старых товаров. Не менять старые 202 объявления.
3. Выбрать файл **только** `01_BONANZA_PILOT_1_FULLSET_DRAFT_TEST.csv`.
4. До окончательного `Import items` сверить скриншот настроек. Если импортёр гарантирует автоматическую активацию, не запускать — безопасное действие не подтверждено.
5. Если тест с `quantity=0` допускается, импортировать только один предмет и проверить в `Add or edit items`, что он имеет статус **Incomplete / not for sale** (или отказывает по понятной причине). Если появился `Ready to post`, ничего не активировать.
6. Проверить название, одну картинку, категорию, цену $295.09, отсутствие ошибочных вариантов и отсутствие доступности покупки. Нажатие `Update Booth` пока запрещено.

## Что НЕ делает базовый CSV

- Не создаёт выпадающие списки `Configuration` и `Color`, не передаёт 12 вариантов пилотного товара и не позволяет выбрать Top/Skirt.
- Не переносит все 4+ фотографии каждого товара: подтверждён только столбец `image` для основной фотографии.
- Не гарантирует автоматическое заполнение item traits, страны производства, размерной сетки, полноценной доставки и политик.
- Не обновляет 202 старых товаров по ID автоматически; совпадение ID при `force_update` может обновить или создать дубликаты. Здесь `force_update` отсутствует.

## Запрещено до следующего шага

- Нельзя загружать CSV с 86 кандидатами массово или нажимать `Update Booth`: одно активирующее действие может выставить уже ожидающие объявления.
- Нельзя разом активировать 207 позиций, пока не проверены категории, состав, цена Full Set, доставка, страна продавца и способ получения коммерческих платежей.
- Нельзя автоматически приводить цену кожи/цвета на трёх старых мужских харнесcах; один отдельный харнесс имеет реальные опции веганской/натуральной кожи по разной цене.
- Нельзя превращать `Black + Gold` в отдельные независимые `Black` и `Gold` покупательские варианты.
