## Import vs API: verified constraints

**CSV:** Bonanza officially documents required `id,title,price,category,description`, plus `quantity` for Google Shopping and recommended `image`. Other columns may contain shipping/traits/variations but the *exact structure of per-variation prices in CSV remains unverified*. Official source: https://www.bonanza.com/blog/selling/Using_CSV_file_to_Import___Update_Listings

**CSV update hazard:** Existing CSV-imported items update only when original `id` is reused and `force_update=TRUE`, or the explicit revise importer mode is selected. Wrong `id` can create duplicate listings. This stage uses separate `THEFEYA-<etsy_id>` IDs and will not match She_Knows old imports without a mapping.

**API:** `addFixedPriceItem` documents an individual `item.variations[].price`, `quantity`, optional SKU and one/two `nameValueList` pairs. More than two variation axes produces `TooManyVariationNames`. If a variation price is omitted, Bonanza can silently use `item.price`; **all variation prices must be explicitly supplied** and checked after import. Setting `item.allowForSale=false` retains draft status. Bonanza API limits imported image URLs to four in that request. Official source: https://api.bonanza.com/docs/reference/add_fixed_price_item . API needs separately authorized developer credentials and seller token; no keys/tokens are stored in this repo.

## Important conflict discovered during QA

Current source records have `price_confidence_status=unverified` in a legacy storefront projection, despite an active **M1 Offer** contract and approved configuration-price table. This staging export deliberately takes exact cents **from active Offer items**, not from the legacy confidence label. This is an authority-layer distinction, not approval to publish on Bonanza.

Some source option values are actually **Color** or **Material**, not `Configuration`. Example: `Основной цвет → Green/Brown/Black` has separate prices; `Материал → Vegan Leather/Genuine Leather` has different prices. A uniform “Configuration” axis would be materially incorrect.
