# M2 owner manufacturing UX — 2026-10-09

Owner screenshots in protected `/admin/company/delivery` showed 207 approved product photos, checked production profile selections and a summary table with some production assignments. **Production read-only SQL at that time showed 0 delivery workspace versions, 0 workspace heads, 0 approvals and 0 v2 shipping receipts**. The checkbox values were only browser draft state; they had not reached the database. Do not reconstruct exact chosen products from the screenshots or claim saved state.

## Owner-confirmed behavior (supersedes old admin editing expectations)

1. **Normal production schedule Mon–Fri.** Exclude Saturday/Sunday from ordinary production, dispatch and shipping/transit date arithmetic. The owner must not tick weekday checkboxes or select calendar-days as a duration basis for this normal workflow. Preserve explicitly entered holidays. A future paid priority-production offering might permit weekends, but requires a separate profile/service, capacity, price and checkout authority; none of that is enabled now.
2. **One normal manufacturing duration per product.** Display all currently available product photos; default filter is **Без назначенного срока** (explicit manual assignment). Once product is saved to 1–3, 3–5, 5–7, 7–10, 10–14 business days or another saved production profile, it disappears from this default filter and is available under that chosen profile and **Все товары**. A separate filter flags mixed old configuration assignments, never hides them silently.
3. **Reassignment by photo.** Selecting an already assigned product from its old profile and applying the new one replaces its product-wide manufacturing duration. Any variant-specific production override for the selected product is cleared to avoid two simultaneously effective manufacturing profiles. **Do not change** exact variant shipping/oversize override or merchandise price, Product Truth, SEO and variants.
4. **One-click `Назначить и сохранить`.** The owner must receive a private service-role-backed immutable draft revision receipt after a single click. Do not create a new revision for each photo checkbox click. The button batches all selected items in one idempotent request, preserves a failed request ID only for an identical retry, and reloads the saved workspace to prove the data actually persisted. If failed, leave the selection and working draft visible; do not falsely claim success. Other editable settings still use the top `Сохранить черновик` button.
5. **Standard/Express are buyer shipping methods**, not two owner-selected production times. The photo batch editor does not assign delivery methods; the separate individual per-product shipping profile editor remains for exceptionally bulky items, with actual packing/rates subject to review. Standard/Express delivery rates remain €19/€35, AU/MX/NZ +€20 per applicable parcel, without activating public checkout.
