# Free IndexNow discovery — 16 November 2026

Owner scope: continue the free organic-growth work, including Bing discovery,
without subscribing to an intermediary service. This adds one UTF-8 ownership
verification file at the root of the production host. It does not create a
Bing account, change Search Release membership, or add a scheduler/API route.

## First submission

After production deployment, verify that the root key file returns HTTP 200
with the exact file content. Submit one JSON batch to
`https://api.indexnow.org/indexnow`, with `host: thefeya.com`, the matching key
and `keyLocation`, and the canonical PDP URLs actually updated by PR #247.
Intersect the changed URL set with the current production sitemap. Exclude
preview/admin/cart/filter/variant/UTM URLs, unchanged hubs and external images.
Record request time, exact URL-set SHA256, count and response in issue #145.

The key file is the protocol's publicly hosted domain-verification text. It is
not a Supabase/Vercel/GitHub/Google credential and grants no site/database access.
No credentials or private shopper data are included in the request.

## Interpretation and future work

- HTTP 200 acknowledges URL receipt; HTTP 202 acknowledges receipt with key
  validation pending. Neither proves crawling, indexing, ranking or AI citations.
- IndexNow shares notifications among participating engines. It is not Google's
  URL Inspection or Indexing API.
- Submit future meaningful URL additions/updates/deletions once per change.
  Do not repeatedly submit an unchanged catalog or create a daily resubmit job.
- Use an authenticated Bing Webmaster account later to inspect reception,
  crawl/index coverage and search performance. Dashboard login is separate from
  this file-based protocol verification.
- The existing GSC validation and accepted manual requests are left alone.
